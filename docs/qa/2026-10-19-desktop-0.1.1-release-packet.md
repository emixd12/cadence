### Build fix

The first two clean builds failed. With Xcode 27.1, `strip` leaves release
proc-macro dylibs that dyld rejects ("mis-aligned LINKEDIT string pool") once
Tauri sets `MACOSX_DEPLOYMENT_TARGET=14.0`. Earlier candidates reused helpers
compiled before the September 29 Xcode update. A one-crate experiment reproduced
the failure with the 14.0 setting and passed without it, in the debug profile, and
with `[profile.release.build-override] strip = false`. That setting now lives in
`apps/desktop/src-tauri/Cargo.toml`. Only build scripts and proc macros are affected.
A stripped release executable with `minos 14.0` built the same way runs normally.
