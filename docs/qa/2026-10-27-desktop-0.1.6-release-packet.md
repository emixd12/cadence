## Release notes

Draft for the owner's approval; plain text for the feed's `notes`:

```text
Cadence 0.1.6 keeps sync working when the server adds new fields. Older Macs keep syncing the data they understand, and nothing they cannot see is lost.

Travel learns your get-ready time and arrival buffer, and you can correct them in Settings › Travel. If you turn on Completion places, Cadence can note whether you completed a Behavior at Home, a saved place or elsewhere. It never saves the position.

Daily Brief can use its own Google Calendar connection, separate from the Timeline's Calendar.

Cadence for Mac needs an Apple Silicon Mac. It has been tested on macOS 27.
```

## Limitations and rollback

Since the [0.1.5 packet](2026-10-23-desktop-0.1.5-release-packet.md):

- Known issue F1 (not a regression): changing the timezone on a linked Mac with an
  archived Behavior stalls sync until it is changed back. Present in 0.1.5 and 0.1.6.
- Installed 0.1.6 keeps schema 20; installed copies have no downgrade path. Rollback stops
  further offers by restoring the saved feeds. The hosted contract migration is
  fix-forward only ([plan](../plans/2026-10-27-sync-compatibility.md)).
- macOS 14 is not tested; every run used macOS 27.0.1 (26A434).
