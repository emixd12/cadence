## Changes since the last published version

The change this release carries is
[PR #398](https://github.com/emixd12/cadence/pull/398), the Google Calendar MCP migration. Desktop
scope:

- **Versioned `purpose=ai_mcp` Calendar broker.** `apps/desktop/src/calendar/google-calendar.ts`
  and `use-google-calendar.ts` request and read the AI grant through the hosted broker
  (`app/api/google-calendar/{connection,calendars}`) with `purpose=ai_mcp`. The Mac stores no
  Google credential; the hosted private schema keeps it.
- **Dual-grant Settings UI.** The shared `components/settings/GoogleCalendarPanel.tsx`,
  `components/briefing/DailyBriefSettingsPanel.tsx`, `lib/ui/google-calendar.ts` and
  `lib/ui/settings-sections.ts` give one `Connected sources → Google Calendar` home for the
  Timeline grant and the AI grant, with the collapsed calendar picker and the `AI features`
  shortcut. `apps/desktop/src/product.tsx` wires it on the Mac.
- `apps/desktop/src/desktop-updater.ts` changed only to read storage through
  `lib/ui/browser-storage.ts`.

Server-side parts of PR #398 (MCP adapter, Model Armor, Chat travel, migration
`20261125120000_reactivate_agent_calendar_mcp.sql`) ship with the web deployment, not this build.

Area-check triggers to confirm against `git diff --name-only <0.1.16 release commit> <release commit>`
before publication: `google-calendar.ts` and `use-google-calendar.ts` changed, so the Calendar
callback replay check applies. `desktop-updater.ts` changed, so check 4 (real updater) applies.
