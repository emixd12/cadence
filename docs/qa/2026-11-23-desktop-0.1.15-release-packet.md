## Release notes

> Cadence 0.1.15 adds Sub-behaviors (routines) and Timeline Semantic Zoom, auto-stops a running timer when you mark an Occurrence Completed, improves Timeline duration estimates (all-time history from 1 tracked completion plus inline duration setting), updates the Advisor avatar, and fixes account-link reconciliation for hosted connector + manual mark pairs. Your data and settings carry over unchanged.
>
> Cadence for Mac needs an Apple Silicon Mac. It has been tested on macOS 27.
