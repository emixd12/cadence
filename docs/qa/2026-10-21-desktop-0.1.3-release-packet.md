## Defects fixed since 0.1.1

All three were found by installed acceptance (Ticket 178):

1. **Stray sign-in callback** (fixed in 0.1.2, `4d9526f`). A replayed callback
   replaced a working linked state with an error.
2. **Refused restart message** (fixed in 0.1.2, `4d9526f`). The reason appeared
   far from the Restart button.
3. **Revoked session** (fixed in 0.1.3, `dcefe7e`). After hosted sessions were
   deleted, Sync now showed "permission denied for function
   read_account_sync_snapshot" instead of the revoked state with Reconnect account.
   Supabase drops the session after the refresh fails, the next RPC runs
   unauthenticated, and PostgREST answers 401 with `42501`. The sync adapter now
   keeps that 401 status, so the failure maps to "revoked". A signed-in 403 keeps
   its message.
