# Desktop 0.1.4 preparation

## Finding and implementation

PR #115 protected linked sessions from callbacks with missing or expired state.
It still reported an Account error when a callback carried an unexpired pending
state while an authenticated session already existed. That error disconnected
the in-memory Calendar client and falsely reported revoked synchronization.

`DesktopAuth.complete` now derives the linked state from the existing session
and attaches the account-switch notice. It consumes the pending flow and PKCE
verifier without exchanging the incoming code or changing the saved session.
The new regression in `tests/desktop-auth-stray-callback.test.ts` failed on the
previous implementation. The existing replay, expiry and signed-out behavior
remain covered.
